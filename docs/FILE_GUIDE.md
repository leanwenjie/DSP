# Project file guide

This guide describes the current project. Source filenames and data/model locations are kept stable because imports, saved scripts and frozen hash manifests depend on them. The root README is now a concise index; the earlier long overview is preserved under `docs/archive/`.

## Root and configuration files

| File | Purpose |
| --- | --- |
| `README.md` | Current project entry point, state, results, run command and remaining work. |
| `exports/DSP-app-Windows.zip` | Laptop-ready app-only archive with frozen classifiers; the one intentionally shared export. See START_HERE.txt inside. |
| `app.py` | Streamlit upload/caption interface; calls scripts/app_inference.py. |
| `.gitattributes` | Allows existing CRLF CSV/license line endings in Git whitespace checks without changing their bytes. |
| `.gitignore` | Keeps environments, data, trained artifacts, secrets and caches out of source commits. |
| `.streamlit/config.toml` | App theme, 10 MB upload limit, headless mode and disabled usage telemetry. |
| `requirements-data.txt` | Base NumPy/Pillow requirements. |
| `requirements-models.txt` | Includes data requirements, then adds scikit-learn and Matplotlib. |
| `requirements-encoder.txt` | Includes model requirements, then adds pinned OpenAI CLIP, torch/torchvision and tokenizer dependencies. |
| `requirements-app.txt` | Includes encoder requirements, then adds Streamlit. These four files are layered, not redundant. |
| `docs/FILE_GUIDE.md` | This explanation of source, results, generated files and cleanup decisions. |

| `docs/CLEANUP_LOG.json` | Exact cleanup paths, duplicate hashes, retained canonical copies and bytes removed. |
| `docs/archive/PROJECT_HISTORY.md` | Preserved earlier project overview; contains historical plans/status, not current instructions. |

## What is unnecessary?

- **Removed:** two verified identical VERITE feature-array copies (~3.91 MiB total), Python bytecode caches and the Matplotlib font cache. Canonical arrays are retained. Exact changes are in CLEANUP_LOG.json.
- **Optional historical data, retained:** ARO annotations (~17 MiB) and scope-options notes. These are not used by the selected project.
- **Optional extension, retained:** 5Pils-OOC data (~242 MiB on disk) and its preparation scripts/reports. They become unnecessary for the final deliverable if that extension is dropped, but are not duplicate files.
- **Backup, retained:** VERITE images.zip (~62.26 MiB). It is not needed for ordinary evaluation after extraction, but protects against loss of the uploaded images.
- **Historical audit, retained:** VERITE access_audit.json and annotation snapshots. They explain access/version decisions and use little space.
- **Regenerable, not pointless:** .venv (~1.6 GiB) and caches. Deleting .venv breaks the current installation until dependencies are reinstalled. Bytecode/font caches may return automatically.
- **Never casually delete:** .git, frozen manifests, model weights, selected thresholds/scalers, unique images, download receipts or test predictions. “Generated” does not mean dispensable for scientific reproducibility.

## Minimum app files versus research files

To run the current app, keep app.py, .streamlit/config.toml, the installed environment or all layered requirements, scripts/app_inference.py and its imported helpers (prepare_data.py and model_inference.py), artifacts/logistic/best_model.npz, artifacts/mlp/model_seed42.npz, reports/baseline/metrics.json, reports/newsclippings_test/frozen_manifest.json and the cached CLIP checkpoint (or access to its official download). The app loads/checks all three heads, even if the default is logistic regression.

Benchmark images, NewsCLIPpings embedding pickles, optional ARO/5Pils data and row-level evaluation predictions are not needed for a new app upload. They are needed for specific research/reproduction checks, including check_app.py. Keep the full research workspace separate from any future app-only distribution. A subsequent laptop-transfer step created `exports/DSP-app-Windows.zip`: the app-only package with frozen small classifiers, Windows installers/launchers and required source. It excludes research datasets and the large CLIP checkpoint (downloaded on first inference). Windows scripts remain untested on Windows; extracted code/model inference was checked in the cloud.

## Hidden and external files

`.git/` is repository metadata, not project code; leave it alone. `.venv/` contains installed third-party packages, not files written for this project. Their internal files are deliberately excluded from the project inventory. `__pycache__/` and Matplotlib cache files are regenerable and may reappear after running Python. The uploaded split archives under `/workspace/attachments/` are outside this repository and were not moved/deleted. Temporary server/install logs under `/tmp/` are also outside the project inventory.
